# راهنمای تست سرویس گزارش‌گیری

## خلاصه

این مجموعه تست ماژول `ReportService` را اعتبارسنجی می‌کند که قابلیت گزارش‌گیری SLA و آپتایم با خروجی اکسل را فراهم می‌کند.

## Invariant های تست شده

### I1-I5: محاسبه آپتایم
- **I1-I2**: `monitorId` باید عدد صحیح معتبر و در دیتابیس موجود باشد
- **I3**: اگر heartbeat وجود نداشته باشد، مقادیر پیش‌فرض برگردانده شود (آپتایم=۱۰۰٪، میانگین پینگ=۰ و غیره)
- **I4**: `uptimePercent` همیشه بین ۰ تا ۱۰۰ باشد
- **I5**: `uptimePercent` حداکثر ۳ رقم اعشار داشته باشد

### I6-I8: محاسبه پینگ
- **I6**: فقط پینگ‌های معتبر (>۰ و !=null) شمرده شوند
- **I7**: `avgPing` به نزدیک‌ترین عدد صحیح گرد شود
- **I8**: اگر پینگ معتبری نباشد، `avgPing` برابر ۰ باشد

### I9-I12: شناسایی حوادث
- **I9**: حادثه فقط وقتی شروع شود که وضعیت از UP(1) به DOWN(0) تغییر کند
- **I10**: حادثه وقتی تمام شود که وضعیت به UP(1) برگردد
- **I11**: `durationMinutes` حداقل ۱ دقیقه باشد (Math.max(1, ...))
- **I12**: حادثه باز در انتهای بازه زمانی با `endDate` بسته شود

### I13-I15: تجمیع داده‌ها
- **I13**: `totalDowntimeMinutes` برابر مجموع مدت زمان حوادث باشد
- **I14**: `outageCount` برابر تعداد حوادث باشد
- **I15**: شیء خروجی شامل تمام فیلدهای ضروری باشد

### I16-I18: خروجی اکسل
- **I16**: فایل اکسل دقیقاً ۲ worksheet داشته باشد
- **I17**: برگه "SLA Summary" شامل ۷ ردیف داده باشد
- **I18**: برگه "Outages Log" شامل ۴ ستون صحیح باشد

### I19-I22: خروجی PDF
- **I19**: کامپوننت از کلاس `no-print` برای المان‌های مخفی استفاده کند
- **I20**: کامپوننت از کلاس `printable-area` برای محتوای چاپ استفاده کند
- **I21**: متد `printPdf()` متد `window.print()` را فراخوانی کند
- **I22**: فیلتر و دکمه‌ها کلاس `no-print` داشته باشند
- **I22-BUG**: قوانین CSS `@media print` وجود ندارند (مشکل شناسایی شده)

## باگ شناسایی شده: عدم وجود CSS برای چاپ

### مشکل

در فایل `src/pages/Reports.vue` از کلاس‌های `no-print` و `printable-area` استفاده شده ولی **هیچ CSS برای چاپ تعریف نشده است**.

### خروجی فعلی (حالت نامطلوب)

وقتی کاربر دکمه "Save PDF" را می‌زند:
- فیلترها و دکمه‌های دانلود همچنان نمایش داده می‌شوند
- خروجی PDF تمیز و حرفه‌ای نخواهد بود
- بخش‌های غیرضروری در PDF چاپ می‌شوند

### حالت مطلوب

باید CSS زیر به بخش `<style>` فایل `Reports.vue` اضافه شود:

```css
@media print {
    .no-print {
        display: none !important;
    }
    .printable-area {
        width: 100%;
        padding: 20px;
    }
}
```

### نتیجه حالت مطلوب

وقتی کاربر "Save PDF" را بزند:
- فیلترها و دکمه‌ها مخفی می‌شوند
- فقط محتوای گزارش (نام مانیتور، آمار، جدول حوادث) چاپ می‌شود
- خروجی PDF تمیز و حرفه‌ای خواهد بود
